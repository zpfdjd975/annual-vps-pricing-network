## 线路怎么选：9929、CN2 GIA、4837、国际 BGP

线路决定了你从国内连上去的手感，也决定了价格。按用途分四层就够了。

**9929 / CUII（联通精品网）**：联通方向优化，电信和移动走起来也不差，是“要国内访问但预算有限”的默认答案。LisaHost 的 199 元/年和 299 元/年两款都在这条线上，区别只在 IP 是不是原生。

**CMIN2（移动精品网）**：移动用户为主的场景更合适，三网表现均衡，价格比 9929 高一档。

**CN2 GIA（电信精品网）**：三网公认最稳的一档，高峰期不绕路，价格也最贵。做面向国内用户的正式业务、对晚高峰敏感，这钱值得花；只是自己 SSH 上去折腾，9929 就够。

**4837 / 国际 BGP**：没有中国方向优化，便宜、带宽给得足，适合外贸站、海外用户为主的服务、爬虫和 Bot。**如果你的访问者都在国外，别为 CN2 GIA 付钱**，那是花钱买自己用不上的东西。

原生 IP 和双 ISP 住宅 IP 是另一个维度，和线路无关。原生 IP 指 IP 的注册归属与机房所在地一致；双 ISP 住宅 IP 指 IP 的 ASN 挂在住宅宽带运营商名下，风控系统看它更像一个真实家庭用户。做 TikTok 运营、跨境电商店铺、流媒体解锁，住宅 IP 才是刚需；只是建站、跑 API，原生 IP 就够，没必要为住宅属性多付钱。

## 几个常被问到的问题

**年付能退款吗？**

官方商品页写的是 48 小时内不满意无条件退款。超过这个窗口，年付款一般不支持退款，下单前把这条当成硬约束看待。

**续费会涨价吗？**

促销价通常有时效，续费时的实际价格以续费当期的官方活动为准。年付前先在购物车确认一次续费价，比事后追问客服省事。

**1 核 1G 到底够不够？**

静态站、Typecho、Bot、探针、轻量 API：够。WordPress 带插件、MySQL 有并发、定时任务扎堆：不够，直接上 2 核。这条判断和商家无关，是这个配置档位的普遍情况。

**9929 和 CN2 GIA 差在哪？**

9929 是联通精品网，联通方向最优，电信移动也不差，价格友好；CN2 GIA 是电信精品网，三网整体最稳，晚高峰表现最好，价格最高。自己用、预算有限选 9929；面向国内用户的正式业务、对晚高峰敏感选 CN2 GIA。

**非原生 IP 和双 ISP 住宅 IP 有什么区别？**

原生 IP 说的是 IP 注册归属与机房位置一致，解决的是“IP 看起来像不像本地”的问题；双 ISP 住宅 IP 说的是 IP 的 ASN 挂在住宅宽带运营商名下，解决的是“IP 看起来像不像真人家庭宽带”的问题。前者建站够用，后者才是 TikTok、电商店铺、流媒体风控场景需要的。

**需要备案吗？**

境外机房不需要 ICP 备案，开通即用。这也是这类年付 VPS 相比国内云主机最直接的优势之一。

**特价年付版的 600GB 流量够吗？**

一个日均几百 PV 的博客、一个只跑 API 的服务，一个月用不到 100GB。图床、下载站、视频中转，600GB 撑不住。先看自己过去三个月的实际用量，再决定是省这 317 元还是买 1000GB 的月付精简版。

年付这件事没有那么复杂：算清折合月价，确认退款窗口，把线路和 IP 属性对上自己的场景，剩下的就是别为了省钱买自己用不上的配置。199 元那款能解决大部分人的问题，剩下的钱留给域名和备份。
